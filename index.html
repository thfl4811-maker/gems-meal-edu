STEP 2 어떤 재료를 넣을까요?

STEP 3 어떻게 요청할까요?

복사해서 젬에 붙여넣으세요

아래 두 가지는 어떤 재료에나 쓰는 만능형입니다. 콘텐츠별로 정교하게 다듬어진 전용 프롬프트는 위 갤러리 카드의 📋 버튼에 있어요.

🤖 기본형 — 처음이라면 이걸로
너는 학교급식 콘텐츠를 잘 만드는 교육용 웹 개발자야. 내가 제공하는 급식 자료를 바탕으로 학생들을 위한 결과물(웹 문서, 웹 인포그래픽, 웹 퀴즈, 웹 게임 등)을 하나의 html 파일로 만들어줘. 디자인은 세련되게, 이모지를 넣고 인터랙티브한 요소도 추가해줘. --- (여기에 식단표·영양교육 자료 등 재료 붙여넣기)
🧩 구조화형 — 결과물을 정교하게
# 역할 - 너는 영양교육 전문가이자 교육용 웹 콘텐츠 개발자야. # 목표 - 내가 제공할 급식 자료를 바탕으로 교육용 웹자료(웹 문서, 웹 인포그래픽, 웹 대시보드, 웹 시뮬레이션, 웹 퀴즈, 웹 게임 등)를 하나의 html로 만들어줘. # 맥락 - 고등학생을 위한 급식·영양 교육 자료야. (대상 학년에 맞게 수정) # 지침 - 입력한 자료의 내용만 사용해서 만들어줘. - 하나의 html 파일로 만들어줘. - 디자인은 현대적으로 세련되게, 흰 배경에 깔끔한 스타일로 만들어줘. - 적절한 이모지를 넣고, 인터랙티브한 요소를 넣고, 휴대폰 화면에 맞는 반응형으로 만들어줘. --- (여기에 식단표·영양교육 자료 등 재료 붙여넣기)
💡 품질을 높이는 키워드 — 디자인: 「현대적인」 「세련된」 「심플한」 / 상호작용: 「인터랙티브」 「클릭 가능한」 「휴대폰 반응형」 · 결과가 아쉬우면 "이 부분을 이렇게 바꿔줘"라고 코드를 다시 주며 요청하세요.
STEP 4 만든 자료, 학생 휴대폰에 띄우기

저장 → 게시 → QR, 딱 세 걸음

지난 연수의 그 예고편, 여기서 이어집니다 😉 완성된 콘텐츠를 링크 하나로 학생들에게 나눠 주세요.

📁 HTML로 저장

젬이 준 코드를 전체 복사 → 메모장(또는 윈도우 메모장·맥 텍스트 편집기)에 붙여넣기 → "다른 이름으로 저장"에서 파일 이름을 index.html로, 파일 형식은 "모든 파일"로 저장 → 저장된 파일을 더블클릭하면 크롬에서 바로 열려요.

✏️ 마음에 안 들면 수정

큰 수정(디자인 변경, 기능 추가, 오류)은 코드를 다시 젬에 붙여넣고 "이 부분을 이렇게 바꿔줘"라고 구체적으로 요청하는 게 빨라요. 오타나 문구 정도는 메모장에서 직접 고쳐도 돼요 — 줄바꿈은 <br>, 굵게는 <strong>글자</strong>.

🚀 Netlify에 올리기

netlify.com 가입·로그인 → Projects 탭 → index.html이 든 폴더째 드래그해 업로드 → 몇 초 뒤 나만의 웹 주소(○○○.netlify.app)가 생겨요. 파일을 고쳐서 같은 자리에 다시 올리면 주소는 그대로 유지됩니다.

📱 QR로 나눠 주기

주소를 복사해 QR코드 생성 사이트(또는 급식소리함 도구)에 붙여넣어 QR 이미지를 만들고, 수업 PPT·교실 화면·급식실 게시판에 붙이면 학생들이 휴대폰 카메라로 바로 접속해요.

💡 더 잘 뽑는 팁 — 같은 프롬프트라도 결과는 매번 달라요. 두세 번 생성해 비교해서 마음에 드는 걸 고르세요. "하나의 html"이란 구조(html)+디자인(css)+동작(js)이 한 파일에 다 들어 있다는 뜻이라, 파일 하나만 옮기면 어디서든 작동합니다.

🔮 수업 장면 상상해 보세요 — 영양교육 시간, 칠판의 QR 하나로 반 전체가 '나트륨 계산기'를 각자 휴대폰에서 실행합니다. 종이 활동지 인쇄는 이제 선택입니다.
